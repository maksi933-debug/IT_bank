# Виджет банковских операций
Данный проект позволит отображать операции клиента.

Домашняя работа 2 го модуля Skypro.

Продолжаем работу над проектом. Код пишется с использованием стратегии тестирования TDD 
являющейся важной частью разработки. Тестирование позволяет не только убедиться, 
что в коде нет ошибок, но и продумать архитектуру наших решений и помогает 
создавать более надежный и поддерживаемый код что гарантирует что 
программа соответствует предъявляемым требованиям. 
## Функционал
```
- Показывает несколько последних успешных банковских операций клиента.
- Умеет обрабатывать информацию как о картах, так и о счетах.
- Позволяет производить сортировку операций.
```

## Тестирование

В проекте используются инструменты `pytest` для запуска тестов и `pytest-cov` для анализа покрытия кода.

### Запуск тестов
Чтобы запустить все тесты, выполните команду в корневой директории:
```bash
 poetry run pytest
```

### Просмотр отчета о покрытии (Coverage)
Чтобы проверить, насколько код покрыт тестами, и вывести отчет в терминал:
```bash
 poetry run pytest --cov
```

Для генерации подробного HTML-отчета:
```bash
 poetry run pytest --cov=src --cov-report=html

После этого откройте файл `htmlcov/index.html` в любом браузере.
```
